# 8. Version Verification Commands

## 8.1 Elasticsearch Version

```bash
curl -s http://192.168.1.100:9200 | grep number
```

## 8.2 Kibana Version

```bash
docker exec kibana cat /opt/kibana/package.json | grep version
```

## 8.3 Winlogbeat Version

```powershell
(Get-Item "C:\Program Files\Winlogbeat\winlogbeat.exe").VersionInfo.ProductVersion
```

## 8.4 Velociraptor Version

```bash
/usr/local/bin/velociraptor --version
```

## 8.5 Caldera Version

```bash
cd ~/caldera
git describe --tags
```

# 9. Upgrade & Maintenance Notes

## Elastic Stack

* Upgrade Elasticsearch, Kibana, and Beats together.
* Keep all components on the same version.
* Recreate containers after updating image tags.

## Velociraptor

* Upgrade the server first.
* Regenerate the client MSI.
* Redeploy updated clients.

## Caldera

```bash
git pull
```

Rebuild the Python virtual environment if required.

## BloodHound

```bash
docker pull specterops/bloodhound:latest
```

# 10. Known Incompatibilities

| Incompatibility                            | Symptoms               | Solution                   |
| ------------------------------------------ | ---------------------- | -------------------------- |
| Elasticsearch 8.x + Beats 7.x              | Index mapping failures | Upgrade Beats to 8.x       |
| Velociraptor Server 0.76.5 + Client 0.75.x | Client offline         | Upgrade client             |
| Winlogbeat in Program Files                | Service startup issues | Install in `C:\Winlogbeat` |
| Python 3.12 + Caldera                      | Dependency conflicts   | Use Python 3.11            |

# 11. Critical Version Pairs

| Pair                         | Required Consistency          |
| ---------------------------- | ----------------------------- |
| Elasticsearch ↔ Kibana       | Same minor version (`8.14.x`) |
| Elasticsearch ↔ Winlogbeat   | Same minor version (`8.14.x`) |
| Elasticsearch ↔ Filebeat     | Same minor version (`8.14.x`) |
| Velociraptor Server ↔ Client | Same version (`0.76.5`)       |
| Caldera Server ↔ Agent       | Same release (`4.14.5`)       |

# Summary

Maintaining version consistency across Elastic Stack components and Velociraptor deployments is essential for stable operation. Before upgrading any component, verify compatibility with dependent services and test changes in a non-production environment.
