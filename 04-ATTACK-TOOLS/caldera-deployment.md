# Caldera Deployment – Nation-State Lab

## Overview

MITRE Caldera is an adversary emulation platform designed to support security validation and detection engineering activities. It maps activities to the MITRE ATT&CK framework and enables organizations to assess monitoring and response capabilities.

### Objectives

- Validate security monitoring coverage
- Generate telemetry for analysis
- Support purple-team exercises
- Test detection logic

---

## Architecture

| Component | Location | Purpose |
|-----------|-----------|----------|
| Caldera Server | Kali VM | Management and orchestration |
| Agent | Windows Endpoints | Telemetry generation |
| Database | Kali VM | Stores operations and results |

---

## Deployment Summary

### Prerequisites

- Kali Linux
- Python 3
- Git
- Network connectivity

### Installation

1. Obtain the Caldera source code.
2. Create a Python virtual environment.
3. Install dependencies.
4. Start the application.
5. Access the web interface.
